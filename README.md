## 📖 About

**Food-King** is a fully responsive front-end template for a restaurant and food store, designed with a clean, modern interface. It covers the full browsing experience — from the homepage and food menu to shop listings, blog, gallery, and contact — built entirely with HTML, CSS, and Bootstrap, with no back-end dependencies.

---

## 📄 Pages

| Page | Description |
|---|---|
| **Home** | Landing page with hero carousel, popular food items & offers |
| **About** | Restaurant story and information |
| **Shop Grid** | Browse the full food/product listing |
| **Shop Details** | Detailed view for a single product |
| **Contact** | Contact form and info |

## 🚀 Getting Started

### Prerequisites

Just a modern web browser — no build tools or dependencies required.

### Installation

```bash
# Clone the repository
git clone https://github.com/Mohammed-Alqerem/Food-King.git

# Navigate into the project
cd Food-King

# Open in browser
open index.html
```

Or simply check out the [live demo](https://stalwart-scone-d21778.netlify.app/).
